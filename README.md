# Chá de Casa Nova — Tayná & Jean

Versão pronta para GitHub Pages.

## Imagens
As fotos dos produtos são carregadas automaticamente por uma URL de geração fotorealista usando o nome de cada produto. Assim, o site não usa mais os desenhos/ilustrações antigos.

O site continua usando os links originais de Mercado Livre, Shopee e Amazon para o botão **Ver produto**.

## Publicação no GitHub
1. Apague os arquivos antigos do repositório.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Aguarde o GitHub Pages publicar.
4. Faça um Ctrl+F5 no site para limpar o cache.

As imagens precisam de internet no navegador para serem carregadas, pois são geradas sob demanda pelo serviço de imagens.
